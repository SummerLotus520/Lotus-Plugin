# Lotus-Plugin

本库已存档，不再维护。

重构插件：[Lotus-ReFactor](https://github.com/MOPELotus/Lotus-ReFactor)

## 迁移流程

警告：使用重构插件会禁用或替代部分插件的部分功能，安装即同意此条款！

1. 将本旧库更新到最新提交，重启机器人，确保迁移指令已加载。
2. 由 bot 主人发送 `#荷花迁移重构`，阅读迁移警告。
3. 发送 `#确认荷花迁移` 完成第一次确认。
4. 发送 `#最终确认荷花迁移` 开始迁移和初始化流程。
5. 迁移完成后，旧插件会被移动到 `plugins/backup/`，避免重启后继续加载。
6. 确认新插件可用后，可发送 `#确认删除荷花旧库` 删除旧库备份。
